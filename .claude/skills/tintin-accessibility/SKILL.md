# tintin-accessibility

Audit current components against relevant WCAG 2.2 AA criteria. Preserve semantic buttons, links, headings, labels, errors, status announcements, focus visibility, dialog focus management and escape behavior. Test keyboard-only and touch interaction, safe-area insets and zoom. Avoid hover-only or color-only communication; target at least 44px touch controls where repository contract requires. Avoid disabling native accessibility features or adding decorative ARIA. Add focused regression tests before declaring completion.

## Completion evidence
Report files touched, targeted verification results, repository commit/PR when applicable, and explicit limits. This Skill never overrides AGENTS.md, DESIGN.md, or production safety rules.
