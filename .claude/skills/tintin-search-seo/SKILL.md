# tintin-search-seo

Inspect actual search routes, canonical catalog data, generated sitemap and routing artifacts before changing them. Preserve selected filters and back/forward history; debounce only when justified, avoid duplicated requests, and keep results accessible. Treat catalog freshness separately from SEO robots and external search-engine indexing. Ensure correct title, description, canonical, OG metadata and structured data only when grounded in real products/prices/availability. Do not generate duplicate sitemaps or conflicting route files; run current validation scripts.

## Completion evidence
Report files touched, targeted verification results, repository commit/PR when applicable, and explicit limits. This Skill never overrides AGENTS.md, DESIGN.md, or production safety rules.
