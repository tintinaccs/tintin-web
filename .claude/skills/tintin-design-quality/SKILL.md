# tintin-design-quality

Read DESIGN.md, official identity docs and canonical tokens/css components first. Identify actual active route/selector before editing. Cover mobile, tablets portrait/landscape, laptop, desktop, zoom, long text, loading and empty states. Avoid generic AI gradients/cards, excessive shadows, duplicated global styles, new fonts and pointless motion. Apply view transitions, skeletons, hover/press feedback only where they improve experience and work with reduced-motion. Reference taste/ui-ux/frontend-design selectively and respect brand above all external advice. Show evidence of before/after and no layout shift.
