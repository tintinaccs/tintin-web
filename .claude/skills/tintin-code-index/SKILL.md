# tintin-code-index

Start from the real affected route and canonical code. Map imports, script tags, event listeners, shared CSS, Firestore queries and generated assets with focused repository search. Compare active vs legacy code, update only proven consumers, and record an evidence-backed dependency map. Graphify CLI is optional and NOT installed by this Skill; do not require downloads or add a heavy graph runtime without proof of need. Prefer existing search and source maps; never mistake a missing text match for unused code.

Respect AGENTS.md, DESIGN.md, security, privacy and production boundaries. Report concrete evidence, files, tests and limitations.
