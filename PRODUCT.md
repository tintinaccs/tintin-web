# Tintín: contexto de producto para trabajo de interfaz

Tintín Accesorios es una tienda web de accesorios y relojes en Paraguay. El sitio existente contiene catálogo, colecciones, detalle de producto, carrito/checkout, cuenta y administración. Este documento orienta la revisión manual de diseño; no define nuevas condiciones comerciales.

Consultar `docs/contrato-logica-tienda.md` y `docs/contratos-comercio.md` para comportamiento comercial, `DESIGN.md` y `docs/identidad-visual-tintin.md` para identidad. Mantener la tipografía Montserrat local, tokens de color y logo original. La fuente ejecutable y el contenido autorizado prevalecen sobre ejemplos genéricos de Skills.

El sitio usa HTML, CSS y JavaScript modular, Pages Functions y Firebase; no introducir React, Expo o Swift por importar una biblioteca de diseño. Las mejoras deben conservar datos, permisos, navegación y estado del carrito.

El pie compartido conserva sus columnas. La franja final presenta el copyright completo aprobado y «Desarrollado por» seguido del símbolo original NOVAK, con destino centralizado y su animación accesible. No redibujar el símbolo ni trasladar la identidad de NOVAK al resto de la tienda.
