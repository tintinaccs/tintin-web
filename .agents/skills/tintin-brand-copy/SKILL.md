# tintin-brand-copy

Read DESIGN.md and docs/identidad-visual-tintin.md before editing. Preserve approved name, visual identity, product facts and Paraguayan Spanish appropriate to actual copy. Replace generic marketing fluff with specific, useful language grounded in real categories/products; never invent promotions, claims, delivery promises or stock. Audit headings, microcopy, error/empty/loading states, checkout messages, SEO titles. Prefer concise human writing; compare before/after with reviewable diff. Do not rewrite existing approved copy without an actual problem or explicit request.

## Completion evidence
Report files touched, targeted verification results, repository commit/PR when applicable, and explicit limits. This Skill never overrides AGENTS.md, DESIGN.md, or production safety rules.
