# Ingeniería visual específica de Tintín
1. Leer DESIGN.md, docs/identidad-visual-tintin.md y tokens CSS canónicos antes de editar.
2. Conservar logo, paleta rosa vigente, Montserrat y componentes originales; no resetear el tema configurado.
3. Consultar design-taste-frontend, ui-ux-pro-max o frontend-design solo para técnicas aplicables, no copiar diseños externos.
4. Usar CSS/JS existente antes de sumar paquetes; medir coste de interacciones.
5. Diferenciar animaciones útiles de decoración; respetar prefers-reduced-motion y entradas touch/keyboard.
6. Estados loading/empty/error/success deben reflejar datos verdaderos; reservar dimensiones para minimizar CLS.
7. Revisar screenshot o navegador en los tamaños afectados; no declarar mejora sin evidencia real.
