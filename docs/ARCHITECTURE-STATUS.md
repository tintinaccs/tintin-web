# Estado de normalización

- 0–10%: inventario, contrato y fronteras arquitectónicas.
- 10–25%: sesión, navegación y perfil.
- 25–45%: carrito y checkout.
- 45–60%: pedidos, API y errores.
- 60–75%: productos, inventario y admin.
- 75–85%: contenido, HTML, CSS y entrypoints.
- 85–95%: CI, auditorías y pruebas end-to-end.
- 95–100%: eliminación legacy y verificación final.
