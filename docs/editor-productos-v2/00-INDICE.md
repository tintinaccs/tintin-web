# Editor de productos — entrada única

La versión vigente es el editor integrado de seis fases con sus correcciones.

La documentación actual está en
[Versión única del editor](../product-editor-refactor/00-VERSION-UNICA.md).

Los informes técnicos de este directorio conservan evidencia fechada y contratos
de las fases. No ofrecen diseños alternativos ni autorizan recuperar propuestas
anteriores. No usar un informe histórico como aprobación del candidato actual.
